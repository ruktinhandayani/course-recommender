WEBSITE REKOMENDASI COURSE - PANDUAN SINGKAT

1. Ekstrak seluruh isi ZIP ini ke satu folder.
2. Pastikan Docker Desktop sudah berjalan.
3. Salin file ".env.example" lalu ubah nama salinannya menjadi ".env".
4. Buka terminal/PowerShell pada folder proyek.
5. Jalankan:

   docker compose up --build

6. Setelah semua layanan siap, buka:

   http://127.0.0.1:5173
