# CRE ML Service Pre-MVP

This repo owns the ML Recommendation Service and standalone admin console slice of Pre-MVP.

## Build Responsibilities

- Generate stable top-K recommendation candidates from the trained artifacts.
- Serve paginated recommendation export for the PHP LMS simulator.
- Implement the shared CRE bearer-token and HMAC request security pattern.
- Provide fixture-mode output for sync/filtering tests.
- Provide a Dockerized admin console for local/research inspection, evaluation review, and manual export refresh.

The PHP LMS simulator and Moodle plugin are outside this repo.

## Generate Export

```powershell
.\.venv\Scripts\python.exe scripts\generate_export.py --top-k 20
```

Outputs:

- `course_recommender_artifacts_final/export/recommendations.csv`
- `course_recommender_artifacts_final/export/recommendations_fixture.csv`
- `course_recommender_artifacts_final/export/recommendation_export_manifest.json`

## Run API

Development defaults are configured through environment variables with the
`CRE_ML_` prefix. Override these for any shared environment:

- `CRE_ML_API_KEY`
- `CRE_ML_HMAC_SECRET`
- `CRE_ML_REQUIRE_AUTH`

```powershell
.\.venv\Scripts\python.exe -m uvicorn course_recommender.api:app --host 127.0.0.1 --port 8001
```

Docker is the preferred local runtime:

```powershell
$env:DOCKER_CONFIG="$PWD\.docker-config"
docker compose up --build -d
```

Open the admin console:

```text
http://127.0.0.1:5173
```

Default local login is `admin` / `admin`. Change this before any shared deployment.

## Endpoints

- `GET /health`
- `GET /recommendations/export?model_version=latest&cursor={cursor}&limit=1000`
- `GET /recommendations/user/{user_id}?model_version=latest`
- `POST /ui/api/auth/login`
- `GET /ui/api/health`
- `GET /ui/api/recommendations/user/{user_id}`
- `GET /ui/api/recommendations/export`
- `GET /ui/api/evaluation/summary`
- `POST /ui/api/refresh/start`
- `GET /ui/api/refresh/status/{job_id}`

All recommendation endpoints require:

- `Authorization: Bearer {api_key}`
- `X-Request-Id`
- `X-Timestamp`
- `X-Signature`

Use `scripts/sign_request.py` to generate manual test headers.

The `/ui/api/*` endpoints are for the admin console and require an admin session cookie.

The API signs the canonical query string with parameters sorted by name. The
helper accepts an unsorted query and prints the canonical version that must be
used for signature verification.

## Project Layout

- `course_recommender/`: inference library, export store, auth, security, and FastAPI app.
- `frontend/`: React admin console.
- `scripts/`: command-line helpers for export generation and signed requests.
- `data/`: local CSV inputs used for training/export generation.
- `course_recommender_artifacts_final/`: generated model, config, tables, and export files.
- `notebooks/`: research notebook and executed notebook outputs.
- `reports/figures/`: paper/report figures generated by notebook runs.
- `tests/`: API, security, and export-store tests.
