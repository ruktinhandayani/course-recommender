# CRE Phase Roadmap

This folder contains the revised implementation roadmap for CRE using three phases:

1. Pre-MVP: ML service plus simple PHP LMS simulator.
2. MVP for skripsi: real Moodle integration.
3. Post-MVP: formal evaluation, paper/thesis packaging, and optional hardening.

Documents:

- `implementation_plan.md`: comprehensive phase-by-phase implementation plan.
- `detailed_todo.md`: detailed checklist for each phase.

The revised split keeps Moodle out of the Pre-MVP phase so the ML model, API contract, dataset flow, and security design can be proven before dealing with Moodle-specific plugin complexity.
